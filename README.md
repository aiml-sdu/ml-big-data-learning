# ML Big Data Learning Platform

An interactive course platform for master's students in machine learning and big data analytics.

This repository currently includes a pilot implementation for the first two lectures:

- Lecture 1: Introduction to Big Data Analytics
- Lecture 2: Data Preprocessing and Feature Engineering

The experience is designed around short concept explanations, interactive visual labs, and end-of-lesson quiz practice inspired by guided learning platforms such as Brilliant.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## GitHub Pages

The site is configured to deploy from the `main` branch through GitHub Actions. In the repository settings, set **Pages -> Source** to **GitHub Actions**.
