# Course materials

This directory contains instructor-owned source inputs. Preserve original files and organize them by teaching function, not by file extension.

Before asking an agent to generate course content:

1. Complete `course-info.md`.
2. Add descriptive filenames such as `week-03-linear-models.pdf`, not `slides-final-v2.pdf`.
3. Keep solutions clearly distinguishable from student-facing questions.
4. Remove student names, submissions, grades, personal data, unpublished exams, and credentials.
5. Record any material that may be used for authoring but may not be republished.

Files here are not deployed automatically. Do not move them to `public/` simply to make an agent-generated page work.
